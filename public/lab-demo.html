1. Asynchronous JavaScript: Callbacks, Callback Hell & Async/Await

In early JavaScript, asynchronous operations relied on nested callback functions. When multiple dependent async tasks are sequenced, it leads to the infamous "Pyramid of Doom" (Callback Hell). Modern JavaScript solves this using Promises and the async/await syntax.

2. Closures & Lexical Scope

A closure is a function bundled together with references to its surrounding lexical state. Closures give functions access to an outer function's scope even after the outer function has finished executing, enabling private variables and data encapsulation.

3. DOM Manipulation & Cross-Site Scripting (XSS) Prevention

Inserting untrusted user input directly using element.innerHTML creates serious Cross-Site Scripting (XSS) vulnerabilities. Safe DOM manipulation relies on element.textContent, document.createElement(), or proper escaping.

5. Node.js Event Loop Architecture & Non-Blocking I/O

Node.js uses a single-threaded event loop with Libuv to handle thousands of concurrent operations without thread blocking. Timers (setTimeout), Microtasks (Promise.then / process.nextTick), and I/O callbacks run in distinct phases.

Note: A standalone backend demonstration script is also included at scripts/event-loop-demo.js. Run npm run demo:event-loop in your terminal to see it directly in Node.js.
